# INT VoiceToText — журнал версий

## v1.0.0 (2026-09-25)

**Полная переработка архитектуры** по финальной спецификации:

### Фронтенд
- React 19 + TypeScript, сборка Vite → `wwwroot`, встраивание в exe
- lucide-react иконки; i18next (RU/EN) с переключателем RU/EN в шапке
- Анимация записи: пульсирующий микрофон + эквалайзер + таймер
- Иконки «?» с подсказками при наведении (hotkey, вставка текста, локальность модели)
- Настройки: захват горячей клавиши «нажал и он понял» — клик по полю → комбинация
- Состояния: готов / запись / распознавание; результат + статус вставки в курсор

### Бэкенд (.NET 9, self-contained single-file win-x64)
- ASP.NET Core (Kestrel, только 127.0.0.1) + SignalR — реалтайм-статусы и результаты
- Photino.NET 4 — нативное окно в правом верхнем углу рабочего стола
- Глобальные горячие клавиши: RegisterHotKey на выделенном потоке (без WinForms)
- Запись микрофона: NAudio WaveInEvent, 16 kHz mono 16-bit → float32 для Whisper
- Распознавание: **Whisper.net + ggml-base — полностью офлайн**, с проверкой целостности
  модели (магический заголовок ggml) и атомарной первичной загрузкой
- Вставка текста: буфер обмена CF_UNICODETEXT + SendInput Ctrl+V в окно, где был курсор

### Надёжность
- Самопроверка сборки: API, index.html, JS-бандл, автозагрузка модели — проверено end-to-end
- exe — настоящий PE self-contained (ранние «exe» были текстовыми файлами — исправлено)
- Диагностика: `int_voicetext_debug.log` рядом с exe (порт, версия, время старта)

## v0.x (исторические, удалены)
- Прототип на Electron.NET / поддельные сборки — заменены текущей архитектурой.
